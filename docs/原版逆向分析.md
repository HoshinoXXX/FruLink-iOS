## 2. 類結構

```
com.tendouaris.frulink
├── MainActivity          : Activity，全部邏輯
│   ├── $1  WebChromeClient   → 文件選擇器（onShowFileChooser，requestCode=1001）
│   ├── $2  WebViewClient     → 背景色切換 / 離線頁 / Live2D 資源攔截
│   ├── $3  Runnable          → 啟動 1.5 秒後自動檢查更新
│   ├── $4  Runnable          → kb() 延遲 160ms 再彈軟鍵盤
│   ├── $5  Thread            → 檢查更新網絡線程
│   │   ├── $5$1 Runnable     → 成功回調（彈更新框 / 「已是最新版本」）
│   │   └── $5$2 Runnable     → 失敗回調
│   ├── $6  OnClickListener   → 「立即更新」→ downloadAndInstall(apk)
│   ├── $7  Thread            → 下載線程（進度 / file too small 校驗）
│   │   ├── $7$1 Runnable     → 更新進度文案

│   └── JsBridge              → @JavascriptInterface × 4（見下）
│       ├── $1 / $2 / $3 Runnable

```

## 4. JS 橋（window.FruLinkApp，原樣復刻到 iOS）

| 方法 | 簽名 | 行為 |
|---|---|---|
| `checkUpdate()` | void | 主線程觸發 `checkUpdate(true)`（手動模式） |
| `exitApp()` | void | `backExit()` → `finishAndRemoveTask()`（失敗回退 `finish()`） |
| `getVersionName()` | String | 返回當前版本名（`appVn()`，異常時 "?"） |
| `kb()` | void | `showKb()`：WebView 聚焦 + `showSoftInput` + 160ms 後重試 |

## 5. 更新流程（與 iOS 版逐行對應）

```
啟動 → 1.5 秒後 checkUpdate(false)
  ├─ checking 防重入（手動觸發時 toast「正在检查中，请稍等…」）
  ├─ 手動觸發 toast「正在检查更新…」
  ├─ 線程 GET version.json?t=<ms>（連接/讀取超時 8 秒）
  ├─ 解析 versionCode(int)/versionName("?")/apk("")/notes("")
  ├─ vc > 本地 且 apk 非空 → showUpdateDialog(myVn, vn, notes, apk)
  │    標題「FruLink 有新版本 v{vn} 啦」
  │    正文「当前版本：v{myVn}  →  新版本：v{vn}\n\n更新内容：\n{notes|常规更新}」
  │    「立即更新」→ downloadAndInstall(apk)
  │    「以后再说」→ 關閉
  ├─ 否則手動模式 → toast「已是最新版本 v{myVn}」
  └─ 異常/失敗 → 手動模式 toast「检查更新失败，请稍后再试」

downloadAndInstall(apkUrl)
  ├─ ProgressDialog「正在下载新版本…」（不可取消）
  ├─ 線程下載 → cache/updates/frulink-update.apk（連接 10s / 讀取 30s 超時）
  ├─ 每 250ms 更新「正在下载新版本… N%」
  ├─ 完成且 >10000 字節 → installApk()
  └─ 失敗 → 「下载失败，请检查网络后重试」

installApk()
  ├─ Android 8+ 且無「安裝未知應用」權限 → 記 pendingInstall，跳系統設置頁
  ├─ 否則 VIEW content://com.tendouaris.frulink.updates/frulink-update.apk
  │    （type=vnd.android.package-archive，flag 0x10000001）
  └─ onResume 中 pendingInstall 恢復後自動續裝
```

## 6. 其餘行為

- **onBackPressed / onKeyDown(BACK)**：WebView 可後退則 `goBack()`，否則退出（返回鍵連點由頁面自行處理）。
- **onDestroy**：`webView.destroy()`。
- **緩存策略**：SharedPreferences 記錄 `lastVersionCode`，版本變化時 `clearCache(true)`。
- **離線頁**：主頁（含 `frulink/index.html`）加載失敗時顯示內置 HTML（標題 FruLink + 「网络好像断开了……」）。
- **Live2D 攔截**：URL 以 `/upload/frulink/live2d/` 開頭時嘗試從 assets/live2d/ 讀取本地文件，
  按擴展名設置 MIME 並加 `Access-Control-Allow-Origin: *`；文件不存在則放行網絡加載
  （本 APK 不含 assets，實際全部走網絡——iOS 版同樣預留該能力）。
